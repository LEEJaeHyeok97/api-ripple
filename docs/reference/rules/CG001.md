# CG001 MISSING_KEY

- 기본 심각도: ERROR
- 수정 제안: `ADD_YAML_KEY`(프로필 설정 파일), `ADD_ENV_VAR`(배포 환경)

## 무엇을 잡나

코드가 **기본값 없이** 요구하는 키가 대상 프로필의 유효 설정(기본 파일 ∪ 프로필 파일 ∪ include/group)에도, 환경변수 목록에도 없다.

## 왜 문제인가

배포는 성공하지만 애플리케이션이 기동 중에 `Could not resolve placeholder` 또는 바인딩 검증 오류로 죽는다.

## 예시

`fixtures/value-basic/src/main/java/com/example/PaymentClient.java`:

```java
@Value("${payment.api-key}")
private String apiKey;
```

`application.yml`과 `application-prod.yml` 어디에도 `payment.api-key`가 없다.

```
config-guard: prod
  ERROR  payment.api-key    PaymentClient.java:9  @Value, 기본값 없음
```

## 고치는 법

다음 중 하나를 한다. 값은 설정 파일에 직접 쓰지 말고, secret이면 환경변수로 준다.

1. 프로필 설정 파일에 키를 추가한다: `src/main/resources/application-prod.yml`에 `payment.api-key: ${PAYMENT_API_KEY}`
2. 배포 환경에 환경변수 `PAYMENT_APIKEY`(또는 `PAYMENT_API_KEY`)를 추가하고 환경변수 목록 파일에도 이름을 적는다.
3. 키가 정말 선택 사항이라면 코드에 기본값을 준다: `@Value("${payment.api-key:}")`

## 오탐 가능성

- 키가 이 도구가 읽지 않는 곳에서 온다: `spring.config.import`, 외부 Config Server, Kubernetes ConfigMap, 명령행 인자. → `ignoreKeys`에 추가한다.
- 환경변수로 주는데 환경변수 목록 파일을 지정하지 않았다. → 프로필별 목록 파일을 지정한다.
