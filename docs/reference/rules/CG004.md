# CG004 UNUSED_KEY

- 기본 심각도: INFO
- 수정 제안: 없음

## 무엇을 잡나

설정 파일에는 있는데 코드 어디서도 요구하지 않는 키. 다음은 "사용 중"으로 본다.

- 코드가 요구하는 키 자신, 또는 그 하위 키(`Map`/`List` prefix, 중첩 객체)
- 다른 설정 값이 `${...}`로 참조하는 키
- `@ConditionalOnProperty`가 읽는 키
- 프레임워크 키: `spring.*`, `server.*`, `management.*`, `logging.*`, `info.*`, `debug`, `trace` (+ `extraFrameworkPrefixes`)

기본 파일(`application.yml`)의 미사용 키는 프로필마다 반복하지 않고 공통(`*`) 섹션에 한 번만 보고한다.

## 왜 문제인가

기동을 막지는 않는다. 이름을 잘못 쓴 키(오타)이거나 더 이상 쓰지 않는 설정일 수 있다.

## 예시

`fixtures/config-properties/src/main/resources/application-prod.yml`:

```yaml
app:
  mail:
    legacy-flag: true
```

```
config-guard: prod
  INFO   app.mail.legacy-flag    application-prod.yml:4  사용되지 않는 키
```

## 고치는 법

1. 정말 안 쓰는 키면 지운다.
2. 오타면 코드가 요구하는 이름으로 고친다.
3. 라이브러리가 읽는 키라면 `extraFrameworkPrefixes`에 prefix를 추가한다.

## 오탐 가능성

- 이 도구가 분석하지 않는 라이브러리·자동 설정이 읽는 키. → `extraFrameworkPrefixes` 또는 `ignoreKeys`.
