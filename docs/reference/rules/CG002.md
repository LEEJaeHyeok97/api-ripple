# CG002 MISSING_ENV_VAR

- 기본 심각도: ERROR
- 수정 제안: `ADD_ENV_VAR`

## 무엇을 잡나

설정 값 안의 **기본값 없는** 플레이스홀더 `${NAME}`이 요구하는 환경변수가 그 프로필의 환경변수 목록에 없다. 같은 이름의 설정 키가 있으면 충족된 것으로 본다.

환경변수 목록 파일을 지정하지 않은 프로필은 이 검사를 건너뛰고 `ENV_CHECK_SKIPPED` 안내(notice)를 남긴다.

## 왜 문제인가

키는 설정 파일에 있으니 CG001로는 잡히지 않지만, 그 값을 읽는 순간 플레이스홀더를 풀 수 없어 기동이 실패한다.

## 예시

`fixtures/env-placeholder/src/main/resources/application.yml`:

```yaml
cache:
  ttl: ${CACHE_TTL:${DEFAULT_TTL}}
```

`deploy/prod.env.keys`에 `DEFAULT_TTL`이 없다. `CACHE_TTL`은 기본값이 있어 요구하지 않지만, 그 기본값 안의 `${DEFAULT_TTL}`은 기본값이 없다.

```
config-guard: prod
  ERROR  env DEFAULT_TTL    application.yml:10  cache.ttl이 요구
```

## 고치는 법

1. 배포 환경에 환경변수를 추가하고, 환경변수 목록 파일(`deploy/prod.env.keys`)에 이름을 적는다.
2. 또는 플레이스홀더에 기본값을 준다: `${DEFAULT_TTL:60}`

## 오탐 가능성

- 환경변수 목록 파일이 실제 배포 환경과 어긋나 있다. 목록 파일을 배포 설정(Helm values, Terraform 등)에서 생성하면 정확해진다.
