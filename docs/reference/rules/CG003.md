# CG003 CONDITIONAL_KEY

- 기본 심각도: WARNING
- 수정 제안: `ADD_YAML_KEY`

## 무엇을 잡나

`@ConditionalOnProperty`나 `@Profile`이 붙은 클래스·메서드 안에서 기본값 없이 요구하는 키가 없다. 조건이 꺼져 있으면 필요 없으므로 ERROR가 아니라 WARNING이다.

## 왜 문제인가

조건이 켜지는 환경(예: `alarm.push.enabled=true`인 운영)에서는 CG001과 같이 기동이 실패한다.

## 예시

`fixtures/conditional/src/main/java/com/example/FcmSender.java`:

```java
@ConditionalOnProperty(prefix = "alarm.push", name = "enabled", havingValue = "true")
public class FcmSender {
  @Value("${alarm.push.fcm-key}")
  private String fcmKey;
}
```

```
config-guard: prod
  WARN   alarm.push.fcm-key    FcmSender.java:11  @ConditionalOnProperty(alarm.push.enabled)
```

## 고치는 법

1. 조건이 켜지는 프로필이라면 그 프로필 설정 파일에 키를 추가한다.
2. 조건이 꺼지는 프로필이라면 그대로 둬도 된다. 경고가 계속 거슬리면 `ignoreKeys`에 추가한다.

## 오탐 가능성

- 이 도구는 조건 값을 평가하지 않는다. `@Profile("prod")`가 붙은 키가 dev에서 없어도 WARNING이 난다.
