# CG005 UNANALYZABLE

- 기본 심각도: INFO
- 수정 제안: 없음

## 무엇을 잡나

정적으로 분석할 수 없어 **추측하지 않고 건너뛴** 패턴.

| 패턴 | 예 |
|---|---|
| SpEL | `@Value("#{systemProperties['user.region']}")` |
| 다른 파일의 상수 | `@Value(Constants.EXTERNAL)` |
| 키 이름 안의 플레이스홀더 | `@Value("${${tenant}.url}")` |
| 변수로 만든 키 | `env.getProperty(name)` |
| 해석할 수 없는 prefix | `@ConfigurationProperties(prefix = PREFIX + DYNAMIC)` |
| 지원하지 않는 프로필 식 | `spring.config.activate.on-profile: "!prod"` |
| 문법 오류가 있는 파일 | Java 파싱 실패 |

예시는 `fixtures/unanalyzable/`에 있다.

## 왜 문제인가

이 부분이 요구하는 키는 검사되지 않는다. 누락이 있어도 config-guard가 잡지 못한다.

## 고치는 법

1. 가능하면 키를 문자열 리터럴이나 같은 파일의 `static final` 상수로 쓴다.
2. 프로필 식은 `prod`, `prod,staging`, `prod | staging` 형태로 쓴다.
3. 의도한 동적 키라면 그대로 둔다. INFO라서 빌드를 실패시키지 않는다.

## 오탐 가능성

없음. 분석하지 못했다는 사실만 알린다.
